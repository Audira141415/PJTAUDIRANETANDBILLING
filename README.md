## 📄 Ringkasan Proyek & Monorepo
Repositori monorepo ini menaungi sistem integrasi jaringan dan penagihan internet:
- **`AUDIRA-NET`**: Sistem integrasi dan manajemen jaringan (Mikrotik RouterOS, Monitoring, dsb).
- **`AUDIRA-BILLING`**: Sistem billing multi-tenant, faktur tagihan, isolir otomatis, payment gateway, dan otomasi notifikasi WhatsApp.
- **`docs/`**: Dokumentasi teknis, audit endpoint, dan panduan operasional.
